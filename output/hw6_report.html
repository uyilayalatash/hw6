Code

Strips hidden text, comments, zero-width characters and links before the model reads anything. Makes HTML docs ~290 tokens shorter.

Design

Trap tools are hidden from the model; code checks the facts and makes the decision. No extra model calls, 124 fewer tokens.

Prompt

254 tokens of safety rules (×2 calls). Mostly cached, so about half a cent per 1,000 documents.

Per document: undefended $0.000333, fully defended $0.000326. The difference is inside the run-to-run noise: the defenses are effectively free.

5Recommendation to the store manager

Turn it on for vendor mail, with all defenses, as a drafting assistant — a person still signs every order.

Cost: at 1,000 documents a day for 30 days the defended, cached agent costs about $9.87 a month (measured $0.000329 per exam document). Without caching it would be about $83.84. Keep caching on.

Why it's safe enough: on 24 test documents (12 practice, 10 exam, 2 of our own attacks) the defended agent got every practice answer right, never triggered an email or payment, and caught both new attacks. Its decision is made by code from the handbook, not by the AI.

Conditions: keep send_email and approve_payment behind human sign-off; review the “hidden items removed” note the agent logs on each document; re-test whenever vendors start using a new file format; and spot-check a sample of decisions each week, since 24 documents is a small test.
